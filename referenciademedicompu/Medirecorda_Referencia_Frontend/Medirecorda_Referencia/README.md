# Medirecorda — referencia visual (maqueta, no aplicación final)

Abre `index.html` con Firefox para ver el diseño.

Archivos:
- `index.html`: estructura de la maqueta.
- `css/estilos.css`: estilos responsive, colores y tema.
- `js/calendario-demo.js`: dibuja días de ejemplo en el calendario.

Esta maqueta usa datos ficticios. No contiene backend, autenticación, recordatorios reales ni almacenamiento. Los botones no registran medicamentos.

Para Claude Code: usa estos archivos como referencia visual para construir el frontend en React + Vite + Tailwind CSS. No copies la lógica ficticia como funcionalidad real. No programes sin aprobación.

Se puede revisar el diseño sin conexión y sin instalar dependencias.
